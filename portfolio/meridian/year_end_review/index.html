Year-End Business Review: Available

A Tableau dashboard comparing FY2025 to FY2024: revenue, gross margin, revenue per employee, and new boutique openings, cut by country, collection, and channel. Fully interactive: every chart cross-filters the others.

The dashboard

The live dashboard, published to Tableau Public and embedded directly below, not a static image. Try it directly: click any country, collection, or channel mark to cross-filter the rest of the view instantly.

Dashboard not loading? Open it directly on Tableau Public ↗

How it was built

Built from three exports pulled via SQL from meridian.db: annual_revenue_margin (year, region, country, collection, channel, units, revenue, cost, and gross margin, 2023 through 2025), boutique_store_roster (56 boutiques with region, country, channel mode, and opening date), and headcount_efficiency (year-end headcount and combined revenue per employee, 2023 through 2025).

Each export was saved as its own Excel file and loaded into Tableau as three separate extracts, rather than a live database connection. This is a year-end snapshot, built once against final FY2025 numbers, not an ongoing operational report. That's a different setup than the Sell-Out Reporting Pack, which connects live to SQL Server via Power Query because it's meant to be refreshed continuously; this workbook was a one-time pull instead.

Scope

FY2025 vs. FY2024 actual-vs-actual. Revenue combines Wholesale (sell-in) and Boutique (Retail and Online). One Dashboard: every view sits on a single canvas.

What each visual shows

  • KPI row: Revenue, Margin, Revenue per Employee, and New Boutiques, each a FY2025 value with the change vs. FY2024.
  • Topline: Revenue by year, one line across 2023, 2024, and 2025.
  • Channels: Revenue split between Wholesale and Boutique.
  • Collections: Revenue by collection, all ten collections.
  • Countries: Revenue by country, all 32 markets.
  • Interaction: selecting a country, collection, or channel mark cross-filters every other view and all four KPI cards on the same click.
